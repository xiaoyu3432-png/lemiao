## 使用约定

### 轮播与营销主题补充

新增 `campaign-family`（周末亲子运动）、`campaign-rope`（跳绳挑战）、`campaign-team`（篮球伙伴）三张原创 2D 插画。首页与原篮球海报组成四张轮播，可自动播放、暂停和手动切换；活动专区使用同组图片展示三个筹备中的主题。图片不包含虚构价格、优惠或招募承诺，标题均使用原生文字组件。

原图位于 `originals/`，运行 JPG 位于 `apps/miniapp/src/static/brand/`。本轮使用内置 image_gen，完整提示词和生成来源见 `campaign-manifest.json` 及 `prompts/campaign-*.txt`。图片压缩后保留生成提示词元数据。

- 首页、列表和详情的课程事实、价格、年龄与时长继续来自服务端。
- 课程与人物配图明确为演示/品牌情境；活动海报不伪装成正在招募的活动。
- 当前页面采用已有篮球运动图标作为中性标识，历史 LM 标志不用于本次展示。
- 几何功能图标保持同一线宽；活动插画不替代操作图标。
- 页面视觉规范见根目录 `DESIGN.md`。
